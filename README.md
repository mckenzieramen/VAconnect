# VA 100 — Interactive Website

A standalone, responsive VA portfolio/service website built with plain HTML, CSS, and JavaScript.

## Included
- Responsive premium dark interface
- Sticky navigation with mobile menu
- Scroll progress indicator
- Animated reveal effects
- Services, process, portfolio, about, FAQ, and contact sections
- Interactive FAQ accordion
- Client-side contact form confirmation
- No external framework or build step required

## Run
Open `index.html` in a browser. For local development, serve the folder with any static web server.

## Note
The contact form is front-end only in this version. Replace the placeholder email/form integration when the final receiving method is selected.
